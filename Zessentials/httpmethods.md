## HTTP METHODS

## 1. HTTP GET =>
    -to get some data from the server
    - browser does get request bydefault

## 2.HTTP POST =>
    - when we want to send data and mutate data in server
    - eg. create a form

## 3. HTTP PUT => 
    - to put something in the server
    - eg. to upload a file(photo)

## 4. HTTP PATCH=>
    - to change an existing entry

## 5. DELETE PATCH=>
    -eg. deleting an account
