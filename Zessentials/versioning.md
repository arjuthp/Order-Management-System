## version

## eg: ^4.18.2

## has 3 parts
    1st part => Major Release => Major and Breaking Update => 4

    2nd part => Recommended Bug fix or security fix=> 18

    3rd part => Minor Fixes => 2 => (optional updates)

## symbols meaning
    ^ => meaning install all recommended and minor fixes automatically

    ~ => approximately eqvt to versions  i.e only last bits changes
